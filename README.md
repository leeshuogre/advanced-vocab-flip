# 李碩高階單字｜近義字配對

翻牌配對高階英文近義字的單頁小遊戲，使用原生 HTML、CSS 與 JavaScript，無須安裝套件或建置工具。適用於 SAT、GRE、TOEFL、IELTS、研究所與教甄等考試準備，也適合想持續突破單字量的學習者。詞庫保留既有 104 組近義字，並以 `New SAT Vocab 1250` 和「台政 112－114 學年研究所單字」擴充 40 組；研究所單字排除標示為「冷僻單字」的詞彙。每次闖關共 5 局，每局從自訂難度區間隨機抽 8 組；五局難度逐漸提高，單次闖關內不重複，不同玩家通常會拿到不同組合。

## 遊玩方式

直接用瀏覽器開啟 `index.html`。翻開兩張卡配對近義字；每翻兩張算一次配對嘗試，每局須在 20 次內完成才能繼續。第 21 次嘗試會結束該次挑戰；成功完成後才會顯示 16 個目標單字的解釋、英文例句與繁體中文翻譯，並要求輸入一個本局單字才能進入下一局。五局完成後，可查看每局時間、配對次數與記憶單字，並下載 PNG 記錄。闖關記錄只保留於當次瀏覽器工作階段，不設後端。

詞對參考 `New SAT Vocab 1250`、`台政 112－114 學年研究所單字` 與既有高階字彙詞庫；例句為原創。部分候選詞對依常見語境配對，遊戲中的中文釋義與例句協助呈現使用情境。
