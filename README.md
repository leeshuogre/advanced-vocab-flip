# LexiFlip｜SAT 近義字配對

翻牌配對 SAT 詞彙的單頁小遊戲，使用原生 HTML、CSS 與 JavaScript，無須安裝套件或建置工具。詞庫保留既有 104 組近義字，並以 `New SAT Vocab 1250` 和「台政 112－114 學年研究所單字」擴充 40 組；研究所單字排除標示為「冷僻單字」的詞彙。依自訂難度排列為 6 關，每關 3 局，每局 8 組。

## 遊玩方式

直接用瀏覽器開啟 `index.html`。翻開兩張卡配對近義字；每局須在 15 次翻牌內完成，才能進入下一局。第 16 次翻牌會結束該次挑戰，玩家可複習 16 個目標單字的英文例句與繁體中文翻譯，再重新洗牌挑戰。最佳紀錄依局數保存在玩家自己的瀏覽器中。

詞對參考 `New SAT Vocab 1250`、`台政 112－114 學年研究所單字` 與既有 GRE/SAT 詞庫；例句為原創。部分候選詞對依常見語境配對，遊戲中的中文釋義與例句協助呈現使用情境。

## GitHub Pages

此專案可直接從 `main` 分支的根目錄發布，不需要 build step。遊戲紀錄只存在玩家自己的瀏覽器中。
