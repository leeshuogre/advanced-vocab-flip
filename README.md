# LexiFlip｜SAT 近義字配對

翻牌配對 SAT 詞彙的單頁小遊戲，使用原生 HTML、CSS 與 JavaScript，無須安裝套件或建置工具。詞庫保留原有 74 組近義字，並參考 `New SAT Vocab 1250` 的難度 Level 4–5 新增 30 組；每局抽出 8 組。

## 遊玩方式

直接用瀏覽器開啟 `index.html`。翻開兩張卡配對近義字，完成後會顯示本局 16 個目標單字的英文例句與繁體中文翻譯。最佳翻牌紀錄只保存在玩家自己的瀏覽器中。

## GitHub Pages

此專案可直接從 `main` 分支的根目錄發布，不需要 build step。遊戲紀錄只存在玩家自己的瀏覽器中。
